## 🎯 Overview
`starey-social-autopilot-make` is an end-to-end Make.com automation blueprint designed to scale agency and executive personal branding. It monitors approved content databases, leverages LLMs to tailor copy per platform, and dispatches posts automatically.

## ✨ Key Features
- **Database Trigger Listener:** Automatically detects approved content briefs from Notion/Airtable.
- **LLM Content Repurposer:** Adapts a single core idea into platform-native formats (LinkedIn, X, Instagram).
- **Multi-Channel Router:** Schedules and publishes assets simultaneously with zero manual intervention.

## 🛠️ Stack & Architecture
- **Automation Engine:** Make.com (Routers, Webhooks & Iterators)
- **AI Intelligence:** OpenAI API / Prompt Chaining
- **Data Format:** Modular JSON Scenario Blueprint
